
# Política de Segurança - PortfolioHUB

## Objetivo

Estabelecer boas práticas para proteger
o código-fonte e o acesso ao repositório
do projeto Study Hub — PortfolioHUB.

## Controle de acesso

O repositório é mantido pela proprietária
do projeto.

O acesso de escrita deve ser concedido
somente a colaboradores autorizados.

## Autenticação

Recomenda-se a utilização de autenticação
em duas etapas para proteger as contas
com acesso ao repositório.

## Proteção de dados

- Não publicar senhas ou tokens.
- Não armazenar credenciais no código.
- Revisar os arquivos antes dos commits.
- Evitar divulgar informações pessoais
  desnecessárias.

## Controle de versões

As alterações são registradas por commits
para permitir rastreabilidade e auditoria.

## Atualizações

As configurações de segurança devem ser
revisadas periodicamente.

## Comunicação de vulnerabilidades

Problemas de segurança devem ser comunicados
privadamente à responsável pelo projeto,
evitando a divulgação pública de dados
sensíveis.
