
# Guia de Contribuição — PortfolioHUB

## Objetivo

Definir boas práticas para contribuições
e manutenção do Study Hub.

## Organização do trabalho

1. Identificar a melhoria necessária.
2. Registrar a tarefa no GitHub Issues.
3. Criar uma branch para a alteração.
4. Implementar e testar a modificação.
5. Abrir um Pull Request.
6. Revisar as alterações.
7. Integrar a mudança à branch principal.

## Padrão de commits

- feat: nova funcionalidade
- fix: correção de problema
- docs: atualização de documentação
- style: alterações visuais
- refactor: reorganização de código

## Segurança

Não adicionar senhas, tokens ou dados
sensíveis aos arquivos do projeto.

## Documentação

Toda mudança relevante deve ser
acompanhada de documentação atualizada.
